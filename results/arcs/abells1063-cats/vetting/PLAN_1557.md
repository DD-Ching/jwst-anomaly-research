## Ordinary explanation tested
The anti axis is the separation vector of two blended knots (two sources, or two clumps of one source), not a single
lensed shape. In weak shear (g ≈ 0.44) an intrinsic shape also explains an anti axis often; that is the sample
shape-noise null (`../arcs.json`), not this test.

## Rules (frozen; same as step 2 for 1316, with the step-2 lesson built in)
- Models and ΔBIC as `PLAN_deblend.md` (F200W, 0.4″ fit radius, M1 one elliptical Gaussian, M2 two round
  Gaussians). Rule `deblend_class` unchanged: `two-knot` if ΔBIC ≥ 10, both knot S/N ≥ 3, separation ≥ 0.10″;
  `single` if ΔBIC ≤ −10; else `undecided`.
- **Gate (validity; changed from step 2 before the run):** the gate that counts is the one at the source's **own
  fitted** fluxes and sizes (M1 shape for the single kind; M2 knot fluxes and σ for the pair, separation set to the
  observed separation rounded to 0.01″). 20 injections of each kind at empty positions 1.5–3.5″ away; ≥ 80 % correct
  for each kind, else the deblend supports nothing. The catalogue-flux gate of step 2 is run and reported, not used.
- **If `two-knot`:** separation PA vs the z_s = 2 prediction (anti ≥ 60°); knot flux ratio across F090W–F200W,
  `different SED` if χ² p < 0.003, else `consistent SED`.
- **Outcomes:** `two-knot` + separation anti + `different SED` → ordinary: blend of two sources, closed;
  `two-knot` + `consistent SED` → clump pair, stays open with that note; `single` / `undecided` → blend not supported,
  stays open; gate failed → test invalid.
