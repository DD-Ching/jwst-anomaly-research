# Roadmap

| Milestone | Goal | Exit criterion |
|---|---|---|
| **M0 Bootstrap** | Durable repo structure, interfaces, CI, agent harness, reuse decisions | Skeleton + 9 bootstrap PRs merged |
| **M1 Catalog-level slice** | Rank sources in program 2736 pipeline catalogs; cutouts + cross-check for top-k; candidate report | One reproducible run on real data with honest results/limitations recorded |
| **M2 Better representations** | Forced/consistent photometry (HLSP catalogs or photutils), image-based features or pretrained embeddings, beat the M1 baseline on injection-recovery | Documented gain over baseline |
| **M3 Lensing-focused search** | Lens/arc-specific features and models (e.g. tangential alignment in cluster fields, pretrained lens finders), lens-model consistency checks | Vetted lensing candidate list with tests recorded |
| **M4 Scale-out** | Many programs/fields via cloud access, batch orchestration, candidate DB at scale | Survey-scale run with provenance |

Direction changes when evidence says so; record why in DECISIONS.md.
