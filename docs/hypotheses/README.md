# Hypothesis invention and destruction (owner direction 2026-10-09)

Every file here is a **hypothesis** (charter label). Nothing in this directory is established physics, and an
untested prediction is not evidence. Nothing is announced outside the repository without the owner.

## Process (D-069)

1. **System A — Physics Invention.** Each group starts from minimal axioms it chooses (an "Ontological Reset"):
   space, time, matter, mass, energy, particles, fields and causality may not be assumed fundamental. Groups work
   without web access and without reading the repository, and are seeded differently so that they do not converge.
   Each group must:
   - define its axioms mathematically;
   - show how an observer recovers familiar physics;
   - state where its world differs from GR + ΛCDM, quantitatively;
   - give predictions that ordinary physics cannot easily mimic, that existing public data can test, and that come
     with an explicit kill criterion;
   - name at least one quantity current searches never measure (the owner's ≥ 30 % exploration budget).
2. **System B — Physics Destruction.** One reviewer per System A text attacks it in this order:
   - internal consistency;
   - conservation, stability and causality;
   - existing observational limits, from verified references;
   - "renamed known idea";
   - novelty.

   Each prediction ends as PASS, conditional PASS or FAIL.
3. **Only predictions that pass B** get a data-inventory check and then search compute, with injection-recovery and
   the full ordinary-explanation chain (docs/methodology.md, `/vet-candidate`), as for W1–W5.
