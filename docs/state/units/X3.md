# X3: W3 inverted microlensing in unselected Gaia epoch photometry

Authorized under the trial (D-083) by S0-2026-10-14 (`docs/state/units/S0-2026-10-14.md`, direction C), after the
owner's request of 2026-10-14 to return to observational searches. Rules: trial-2026-10-13.2.

## Premises
- **Hypothesis** (not a result): negative-mass compact lenses exist in the Galaxy.
- **Signature.** A source behind such a lens shows the D-047 W3 light curve: an achromatic dip toward the blend
  level lasting 2t_E√(4 − u₀²), between two caustic brightenings (n = 1, ε < 0; `exotic_sim`).
- **What is new.** D-061 showed that Gaia DR3's microlensing selection removes W3 events. X3 screens light curves
  that were never selected by variability:
  - now: the Gaia Andromeda Photometric Survey, 1,257,319 sources around M31, all with G/BP/RP epoch photometry;
  - later: DR4, if its epoch photometry covers all sources (scheduled 2 December 2026; coverage not yet stated by
    ESA, so an assumption).
- **Ordinary models to beat:**
  - eclipsing binaries (periodic, nearly achromatic);
  - dust dimmers: YSO dippers and R CrB stars (reddening);
  - long-period and semi-regular variables;
  - positive-mass microlensing (a brightening);
  - Gaia transit outliers, crowding near M31, scan-angle photometry.
- **Expected yield on GAPS:** essentially none. The Galactic optical depth toward M31 (b ≈ −21°) is tiny. GAPS is
  the validation set and a first null; DR4 is the decision-changing data set.
- **Labels (T5).** Injections are `simulated`, light curves are `observed`, fits and rates are `derived`.
  Development data are never called held-out.

## Data split (frozen 2026-10-14, before any light curve was fetched)
- **dev:** GAPS sources with `source_id % 10 == 0`. Used for screen design, positive controls and false-alarm
  calibration.
- **held-out:** all other GAPS sources. Not fetched or inspected until the G1 screen and its thresholds are frozen
  in this file.
- **DR4:** the true out-of-sample set, run once with the frozen screen.
- **Ordinary-dimmer reference:** DR3 sources with epoch photometry and a DR3 variability class of eclipsing
  binary, YSO or R CrB-type, or LPV. Used only to measure mimic rates, never to tune thresholds silently: any
  change made after seeing them is recorded as post hoc.

## Stages and gates (written before computing)
**G0. Positive controls and false alarms on dev.** Budget 4 h.
- Screen v0 is the D-057 fitter flag: ΔBIC(N1neg − best of PSPL/PAR) < −10 (`w3_microlensing.P.flag_dbic`), on
  G epoch photometry with errors rescaled as in D-061.
- Positive controls: W3 injections (`w3_microlensing.inject_w3`) into real dev light curves with G_base ≤ 19.
  - Cells: t_E ∈ {10, 30, 100, 300} d and ρ ∈ {0.01, 0.1}.
  - Draws: u₀ ~ U(0, 2), t₀ ~ U(first, last epoch), source fraction f_s ~ U(0.5, 1).
  - Plus PSPL injections, which must **not** be flagged as W3.
- False alarms: the flag fraction on non-injected dev light curves (G ≤ 19), and on each ordinary-dimmer class.
- **Gate:**
  - **Continue to G1** if the mean W3 efficiency over t_E = 30, 100 and 300 d is ≥ 0.20 **and** the dev flag
    fraction is ≤ 0.01.
  - **Stop the unit** if the efficiency is < 0.05 in every cell. Gaia's cadence then cannot test W3; record this
    as D-061's measured answer.
  - **Otherwise** one screen revision is allowed. It is recorded as post hoc and re-gated on a fresh dev
    subsample.

**G1. Vetting features and the held-out GAPS screen.** Budget 8 h.
- Add to the screen, frozen here before the held-out data are fetched:
  - achromaticity: the BP − RP change over the dip must be consistent with zero, against dust reddening;
  - non-periodicity: no second dip of matching depth and shape;
  - the existing D-057 vetting chain (feature coverage, seasons, refits).
- Re-measure efficiency and false alarms on dev.
- Then run the held-out GAPS set once, and vet flags with `/vet-candidate`.
- **Output:** candidates (if any) as needs-human, and a W3 rate limit toward M31 with its efficiency.
- **Gate:** the frozen screen keeps dev efficiency ≥ 0.15 with ordinary-dimmer flag fractions recorded per class.

**G2. DR4 readiness.** Budget 4 h, after 2 December 2026.
- Confirm the DR4 epoch-photometry coverage, the data volume and a streaming plan (CLAUDE.md cloud-disk rule).
- Run the frozen screen. This is the decision-changing result: an all-sky W3 limit or candidates, compared with
  MOA-II's Γ₉₅ ≈ 1.2–7.4 × 10⁻⁸ per star per year (bulge).

**Total budget:** 16 h. **Used:** S0 0.9 h (counted in the S0 file).

**Stop conditions:**
- the G0 stop gate;
- DR4 does not publish epoch photometry for unselected sources: then G2 is replaced by GAPS-only conclusions;
- the trial ends (2026-11-09) before G2: G2 waits for the owner's next authorization.

  - The dev list is queried per level-5 HEALPix `source_id` range. Sync TAP caps results at 50,000 rows and
    anonymous jobs at 60 s, so the first query was silently truncated at 50,000 rows in storage order. It was
    discarded.
  - Dev sources with G ≤ 19: **106,379**.
- **Timing pilot** (seed 314, n = 50): 150 fits in 40 s on 4 cores.
  - It flagged 3 / 50 unselected light curves (6 %), and gave a W3 efficiency of about 0.75 over t_E = 30–300 d
    (small cells).
  - This is a timing run, not the gate sample. The screen was **not** changed after seeing it.
- **Gate sample:** seed 2026, n = 1,000 dev light curves, run as frozen above.
