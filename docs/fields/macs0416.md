# MACS J0416.1−2403 (Hubble Frontier Fields)

Field note for the HFF CATS map models (D-035). MACS0416 is a merging cluster at z = 0.396. Every number below is
`observed` (catalogue values, images), `derived` (our measurements) or `model_prediction` (CATS v4.1 maps), and every
threshold is an ASSUMPTION. No physical interpretation is made.

## Data (accessed 2026-10-08)

- **JWST:** CANUCS GTO program 1208, NIRCam observation 4, association `t002`, all 8 PUBLIC level-3
  bands: `jw01208-o004_t002_nircam_clear-{f090w,f115w,f150w,f200w,f277w,f356w,f410m,f444w}`
  ([`configs/macs0416.yaml`](../../configs/macs0416.yaml)).
  - One MAST query per program (1176 PEARLS, 1208 CANUCS) listed three PEARLS epochs (o211/o212/o213, `t009`,
    8 bands each, F200W 2,920 s) and CANUCS o004 (8 bands, F200W 6,399 s) plus CANUCS medium-band observations
    (o023–o025). CANUCS o004 was chosen for depth.
  - The cluster centre (RA 64.0381, Dec −24.0675) lies in one NIRCam module (MAST `s_region`, Dec −24.101 to
    −24.042); the other module images a flanking field to the south-east.
  - `_cat.ecsv` for every band (2.6–5.5 MB, **jwst 3.0.0**, photutils 3.0.0). `_i2d.fits`: SW 1.65 GB, LW 0.34 GB;
    never downloaded, read only by S3 byte range. The i2d grid is rotated by 48.0° from north-up.
  - Manifests: `data/manifests/macs0416.ecsv` (8 catalogues with sha256) and `data/manifests/macs0416_products.ecsv`
    (all 16 level-3 products with S3 URIs).
- **DJA matched photometry / photo-z: none.** The DJA v7 mosaic index
  (`https://s3.amazonaws.com/grizli-v2/JwstMosaics/v7/index.html`, 2026-10-08) lists no MACS0416 field, and HEAD
  requests for `macs0416`, `macs0416-clu`, `macs0416clu`, `m0416` and similar names (v7.0–v7.5, `fix_phot.fits`,
  `fix.photoz.tar.gz`, `fix.eazypy.zout.fits`) return 403/404. So the radial screen runs without photo-z, and the
  config has no `matched_photometry` block. CANUCS DR1 (docs/landscape.md) has EAzY photo-z for MACS0416; not used.
- **Lens model:** CATS v4.1 HLSP maps and `arcs.txt` / `params.txt`, pinned in `lensmodel.HFF_CATS` (D-035).
  - `params.txt` has no `z_m_limit` lines, so every system's redshift comes from `arcs.txt`.
  - Its header gives image-plane optimisation, Chi2pos 243.47 for dof 124.
- **Frame:** the 54 `arcs.txt` images with an F200W catalogue source within 0.5″ sit at a median dRA cos δ +0.208″,
  dDec −0.025″ (HST frame → JWST). This is close to El Gordo's +0.224″, −0.016″ (D-034).

## Lens model check: `validate` (2026-10-08)

`python scripts/lens_consistency.py --model macs0416-cats validate` (default solver grid 0.25″):
- κ median relative difference 2.5e-3 (627 points); μ(z = 2) 3.7e-4 (713 points); both as in D-035.
- Image plane: 116 of 116 images solved. **rms 1.57″, max 11.31″ (26.1)**, against the quoted 0.72″: the gate
  (≤ 1.5 × quoted = 1.08″, ASSUMPTION) fails, which agrees with the `MODELS` setting (map only).
- Shared matches: 26.1/26.2/26.3 (all three on one predicted image) and 122.2/122.3/122.4.

### System 26 diagnosis

| Test | Result |
|---|---|
| Redshift | `arcs.txt` z = 3.2380 (not a round placeholder); `params.txt` has no `z_m_limit`, so 3.238 is used. Source-plane rms of the three back-traced images: 0.122″ (z 2.9), 0.073″ (z 3.238), minimum 0.071″ (z 3.30), 0.091″ (z 3.6). **The redshift is not the cause.** |
| Images in JWST | All three have an F200W catalogue source at 0.19–0.22″ (labels 3023, 3032, 3038; isophotal AB 26.0, 26.6, 27.4), the frame offset above. Cutouts (F150W/F200W/F277W/F444W) show compact knots at all three positions on a thin arc about 15″ long that runs along the predicted tangential direction (PA 127–138°). **Observed.** |
| Magnification | Model |μ| at z = 3.238: 142 (26.1), 153 (26.2, negative parity), 69 (26.3). |
| Image-plane solve | The mean back-traced source lies **within 0.001–0.005″ of the fold caustic**: moving it that far toward any image's own source gives 3 images. On the 0.25″ solver grid the merging 26.1/26.2 pair is missed: 1 image is predicted, 11″ from 26.1. Each of 26.1 and 26.2 traced alone gives 3 images. |
| Finer grid | `validate --grid-step 0.1`: 3 images predicted; residuals 26.1 0.15″, 26.2 1.01″, 26.3 1.12″. |

**Diagnosis:** a solver-resolution failure at a fold caustic: a high-magnification pair straddling the critical curve
whose source sits about 0.005″ from the caustic. It is not a wrong or placeholder redshift, and the images are real.

**Image-plane rms (model_prediction):**

|---|---|---|---|---|

## Radial screen (2026-10-08)

`python scripts/exotic_screens.py --model macs0416-cats radial --catalog <F200W jw01208-o004_t002 cat> --max-radius 100`
(no `--photoz`: none exists, see above).

ASSUMPTIONs (script defaults): ellipticity ≥ 0.5, semimajor σ ≥ 2 px, isophotal S/N ≥ 10, grid 0.5″, line tolerance
1.0″, line length ≤ 15″, ≥ 3 lines, dark centre > 1″ from a catalogue source, model-radial veto μ_r ≥ 3, 200 random
draws.

- 778 elongated sources within 100″; 24 dropped as diffraction-spike segments.
  - Without photo-z, 0 are dropped as not behind the lens, so cluster members stay in the sample.
- 139 are `anti`, 137 after the model-radial veto.
- **98 centres against a null mean of 99.6 (p95 120); max 7 lines, p = 0.29.** No centre has p_random < 0.05.

| Centre (model x, y ″) | RA, Dec | lines | nearest source | p_random | Verdict |
|---|---|---|---|---|---|
| (28.0, −25.0) | 64.02958, −24.07443 | 7 | 2.47″ (dark) | 0.29 | not significant; noise segments (below) |
| (34.0, −36.5) | 64.02776, −24.07762 | 5 | 0.24″ | 1.0 | not significant; shares sources 780, 945 with the centre above |
| all other 96 | | 3–5 | | 1.0 | not significant |

**Strongest centre, checked anyway** (F150W/F200W/F277W/F444W cutouts from S3 byte ranges, looked at):
- **Faint segments.** The 7 line sources (labels 780, 818, 823, 945, 1202, 1239, 1303) are faint segments: isophotal
  AB 28.0–28.7 and catalogue isophotal S/N 14–22, but **aper50 S/N 1.6–4.0**. Isophotal areas are 27–52 px, and
  `is_extended` is false for all of them.
- **Not visible in cutouts.** 2″ stamps (raw and smoothed) show no visible source at any of the 7 positions in any band.
  Forced 0.15″-radius aperture fluxes, against the scatter of 200 random apertures within 9″, give S/N between −1.2 and
  +1.5 in all four bands. Their position angles are noise-dominated.
- **A chain, not convergence.** The 7 sources lie on one loose chain (PA 28.7°, perpendicular rms 1.2″, 21.5″ long),
  with the centre in a gap of that chain. They are not lines converging from different directions.
- **Not a diffraction spike.** No point source brighter than AB 20 (56 in the catalogue) lies within 3″ of the chain
  line. The chain PA is not on the mosaic's row or column axes (138°/48°) either.
- **Sensitivity run.** The same screen on the catalogue restricted to aper50 S/N ≥ 5 (4,104 of 5,075 rows) gives 454
  elongated, 61 anti, 59 after the veto, and 7 centres against a null mean of 6.8 (p95 13). The maximum is 3 lines,
  p = 1.0. The centre disappears.
- **Catalogue S/N caveat.** Of the 137 screened `anti` sources, 66 have aper50 S/N < 3. The isophotal S/N cut lets
  through faint, low-surface-brightness segments in this jwst 3.0.0 catalogue.

**Result: null; no exotic-lens candidate, nothing for `/vet-candidate`.**

`images` and `fluxratio` were not run: the image list is gated off (D-035).
